# 功能说明

当前已经可用的能力。界面截图见 [界面](界面.md)，通路和数据流见 [架构](架构.md)。

## 打印机

- 局域网 mDNS 扫描，或按网段探测 8883。选中后补访问码即可添加。
- 手动填写 IP、序列号、访问码。访问码加密存放。
- 一台打印机只有一条记录，唯一键是序列号。
- 两条读取通路，局域网优先：
  - 能连上打印机 `8883` 时，用访问码直连，订阅 `device/{序列号}/report`。
  - 直连失败且已登录拓竹账号时，改订拓竹云上同一序列号的状态。不新建第二台。
- 设置页登录拓竹账号：打开官方登录页，回调里的 ticket 换成令牌。账号下的设备按序列号对上已有打印机。
- 不要求打开「仅局域网」。打印机保持云端登录时，Bambu Handy 的远程打印可以继续用。本系统不代替 Handy 下发打印。
- 实时显示在线、打印进度、任务名、当前槽和 AMS 四槽的材质、颜色、剩余。
- 每个槽可以绑定库存。结算时绑定优先，没有绑定再按颜色自动匹配。

## 库存

- 按「材质 + 颜色 + 品牌」记账。相同组合再次入库会合并到同一条并累加剩余克数。
- 拍照识别标签上的材质、颜色、重量、品牌，也可以完全手填。
- 每条库存画成一卷耗材：绕线用这条耗材的颜色，轴心是黑的，上面是相对单卷克数的剩余百分比。多卷时百分比按单卷封顶，克数仍写在旁边。
- 详情里可以直接填写调整后的剩余克数。同一页列出用到这条库存的打印任务和手工扣料。
- 剩余克数、卷数、单价、总价。盘点调整和入库都进流水。
- 删除只归档，历史还在，可以恢复。
- 颜色码映射成「白色 / 灰色」这类库存颜色名，供自动扣减使用。
- 设置里按品牌填写元/千克。报告里的成本用这个单价；没填的克数单独计为未设单价。

## 任务与消耗

- 打印开始、结束由打印机上报的状态推导。
- 结束时扣库存，顺序是：切片里的用料克数，其次开始时的预估，对不上的留在任务详情里手工补录或撤销。
- 同一任务、同一槽、同一段不会重复扣。
- 流水可以冲销。报告按日、周、月看消耗。每根柱按耗材颜色分段，成本按品牌单价估算。

## 生产（合盘与下发）

- **合盘向导** `/production/merge`：把多个已切片 3MF 的指定盘合成一个可无人值守连续打印的 `.gcode.3mf`——自动注入换盘码、全局重映射耗材槽位、重写元数据。上传后自动统计盘数、时长、各槽位耗材用量与换盘次数。
- **换盘码三档预设**：保守 / 均衡 / 快速（力控推盘 G380），`/settings/swap-codes` 可预览渲染出的 G-code 与单次换盘耗时，并生成不加热、不耗料的空跑测试文件。
- **产物库** `/production/gcodes`：合盘产物登记入库（盘数、时长、克重、槽位清单、MD5），支持下载、删除和直接下发到打印机（FTPS 上传 + MQTT 启打），下发状态可追溯。
- 合盘算法是纯标准库（`backend/app/plate_merger/`），细节见其目录内 README。

## 数字孪生与设备控制

- **设备详情页** `/printers/[id]`：SSE 实时推送，展示进度、层数、喷嘴/热床/腔体温度、风扇、灯光、速度档、AMS 四槽颜色与余量。
- **数字孪生**：A1 真实 CAD 模型（STEP→GLB，25 部件）+ 参数化 AMS Lite。喷头/龙门随层高升降，打印件随层数生长，温度让部件变色，风扇与腔灯联动，HMS 故障按模块号让对应部件红闪。
- **设备控制**：暂停 / 恢复 / 停止（二次确认）、速度四档、腔灯开关、温度设定、轴移动 / 回零 / 挤出、AMS 换料、校准。打印中自动禁用运动类控制，避免撞件；G-code 直发走白名单与温度上限校验。
- **HMS 故障诊断**：故障出现即推送 `HmsError` 事件，按 ecode 匹配内置 593 条中文码表给出文案与处理建议，按模块号（AMS/主板/运动控制）定位部件。

## 界面

- 页面是浅灰底和白卡片，强调色用蓝。耗材自己的颜色只出现在耗材卷和统计柱上。
- 仪表盘、打印机、生产、库存、任务、报告、设置。手机和 iPad 竖屏用底部标签，更宽的屏幕用顶部导航。
- 可安装到主屏。断网时打开已缓存的壳，并进入离线页。
- 浅色、深色、跟随系统。数字孪生视图的背景与光照跟随主题（摄影棚渐变 + IBL 布光）。
- 窄屏上的宽表变成带字段名的卡片，按钮留在屏幕里。
