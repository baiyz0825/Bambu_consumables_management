# 当前进度与已实现功能

功能以 [功能说明](功能说明.md) 为准，通路以 [架构](架构.md) 为准。生产模块与数字孪生的分阶段设计见外层仓库 `docs/自动换盘完整技术方案.html`。

---

## 1) 当前整体链路状态（已跑通）

### 数据流
- `collector`（采集器）：
  - 局域网直连拓竹打印机 MQTT（TLS 8883），订阅 `device/<serial>/report`
  - 保存 `raw_events`（原始 payload）与 `normalized_events`（41 个标准化字段，含温度/层数/风扇/灯/HMS/换料三要素）
  - 事件类型：状态机推导 + `HmsError`/`HmsCleared`（优先于状态翻转）
- `backend`（API + 事件处理）：
  - 轮询 `normalized_events`，生成/更新 `print_jobs`；结束时结算扣料并重算库存
  - 已下发的合盘产物通过 `gcode_file` 自动关联到打印任务（`merged_artifacts.job_id`）
  - 生产 REST：合盘 13 端点 + 设备控制 13 端点 + HMS 码表 3 端点
- `frontend`（Next.js UI）：
  - 打印机列表实时展示；`/printers/[id]` 设备详情（SSE 实时面板 + 数字孪生 + 设备控制）
  - `/production/*` 合盘向导、产物库；`/settings/swap-codes` 换盘码管理

## 2) 已实现功能清单

### 2.1 打印机（Printers）
- 新增/删除打印机（IP/Serial/LAN Code，LAN Code 加密存储）、mDNS + 网段扫描
- 双通路：局域网优先，失败改读拓竹云同一序列号
- 实时展示：在线状态、`gcode_state`、进度、任务名、AMS 四槽材质/颜色/剩余
- **设备详情页**：温度（喷嘴/热床/腔体，达标变色）、层数双进度条、风扇、灯光、速度档、阶段码、HMS 告警卡（中文文案）

### 2.2 事件采集（Collector）
- MQTT 连接（用户名 `bblp`，TLS 8883）、原始 + 标准化双写
- 41 个标准化字段（T0 扩充 +30）：温度 5、层/阶段 4、风扇 4、灯、速度 2、故障 3（hms 含 ecode + 模块号）、换料 3、归零等
- `HmsError` 优先于 `gcode_state` 状态机——故障出现时状态可能仍是 RUNNING
- 历史回补脚本 `scripts/backfill_normalized.py`（enrich 模式只补缺失键，支持 `--dry-run`）

### 2.3 作业（Jobs）与扣料
- PrintJob 生成/更新，job_key 去重（task_id 优先）
- 扣料：AMS remain 差值 → 切片用量优先的结算顺序；绑定优先、颜色匹配兜底
- 库存剩余重算；流水冲销；报告按日/周/月分色统计与品牌单价成本

### 2.4 生产模块（合盘全链路）
- **M1–M6 算法**：3MF 读写、G-code 三段解析、换盘码渲染（三档预设）、槽位重映射、拼接注入、元数据重写、输出校验——纯标准库，20 个模块
- **REST 13 端点**：upload / analyze / merge / artifacts / outputs / download / presets / render / probe / test-file / plan / dispatch
- **产物落库**（`merged_artifacts`）：耗材清单、来源盘、合盘参数、MD5、下发状态（draft→dispatched→printing）
- **下发**：FTPS 上传 + MQTT 启打，成功后自动回写状态并关联打印机
- **安全**：API 只接受上传目录内路径（防穿越）、512MB 上限、仅 `.3mf`

### 2.5 数字孪生与设备控制
- **孪生**：A1 官方 CAD（STEP→GLB，25 部件）+ 参数化 AMS Lite；喷头/龙门随层升降、打印件随层生长（gcode 层索引驱动 XY）、温度变色、风扇/腔灯联动、HMS 按模块红闪
- **层索引**（`plate_merger/layers.py`）：`;LAYER_CHANGE` / Z 变化双策略切层，`layer_num` → Z + XY bbox，支持序列化缓存
- **设备控制 13 端点**：暂停/恢复/停止、速度 1-4、灯光、gcode 直发、轴移动、回零、挤出、AMS 换料/控制、校准、提示音
- **三条安全红线**：打印中禁运动（409）、G-code 白名单、温度上限（喷嘴 300℃/热床 120℃）

### 2.6 HMS 故障诊断
- 码表：Studio 中文码表导出 593 条（`app/resources/hms_codes.json`），容器内无需安装 Studio
- 接口：`/hms/meta`、`/hms/codes`、`/hms/lookup?ecodes=…`（批量 ≤200）
- ecode 归一：`attr+code` → 8 位 hex，前两位即模块号（07=AMS、05=主板、03=运动控制）

## 3) 当前缺口 / 已知限制

- **未真机验证**：孪生联动与设备控制基于协议字段与演示数据；真实 A1 的 `lights_report` 等字段结构可能有差异
- **切片用量归因未接入合盘**：`analyze` 已能算每槽用量，但预约/扣料链路仍以固件上报为主（§15 计划项）
- **xcam AI 检测**：A1 无此模块，未采集
- **报告按换盘批次维度**：未扩展
- 产物库下发的服务端路径预填 `/tmp/plate-merger/`，容器 `tempdir` 不同时需手改（建议后续提为配置项）

## 4) 标准化字段（normalized_events.data_json）

41 个字段，主要分组：

- 基础：`gcode_state` / `progress` / `mc_remaining_time` / `task_id` / `subtask_name` / `gcode_file` / `gcode_start_time`
- 温度：`nozzle_temper` / `nozzle_target_temper` / `bed_temper` / `bed_target_temper` / `chamber_temper`
- 层/阶段：`layer_num` / `total_layer_num` / `mc_print_stage` / `mc_print_sub_stage`
- 风扇/灯/速度：`cooling_fan_speed` / `big_fan1_speed` / `big_fan2_speed` / `heatbreak_fan_speed` / `lights` / `spd_lvl` / `spd_mag`
- 故障：`hms[{attr, code, ecode, module, action, timestamp}]` / `print_error` / `fail_reason`
- AMS：`tray_now` / `tray_pre` / `tray_tar` / `ams_trays` / `filament`

## 5) 关键接口（便于联调/排障）

- 打印机：`GET/POST /printers`、`GET /printers/{id}/latest-report`、扫描与网段探测
- 实时：`GET /realtime/printers`（SSE）、`GET /realtime/printers/{id}`（SSE）
- 生产：`POST /plate-merger/upload` → `POST /plate-merger/analyze` → `POST /plate-merger/merge` → `GET /plate-merger/artifacts` → `POST /plate-merger/dispatch`
- 换盘码：`GET /plate-merger/presets`、`POST /plate-merger/presets/{id}/render`、`POST /plate-merger/test-file`
- 控制：`POST /printers/{id}/pause|resume|stop|speed|led|gcode|move|home|extrude|calibrate|ams/*|option`
- HMS：`GET /hms/meta`、`GET /hms/codes`、`GET /hms/lookup?ecodes=…`
- 库存/任务：`/spools`、`/tray-mappings`、`/jobs`
