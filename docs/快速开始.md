# 快速开始

## 本机

需要 Python 3.12+、Node.js 18+、uv。

```bash
git clone https://github.com/baiyz0825/Bambu_consumables_management.git
cd Bambu_consumables_management
uv venv .venv
uv pip install -r backend/requirements.txt
uv pip install -r collector/requirements.txt
cd frontend && npm install && cd ..
./run_local.sh start
```

- 界面：`http://localhost:3000`
- API 文档：`http://localhost:8000/docs`
- 数据文件：`data/consumables.db`

```bash
./run_local.sh stop
./run_local.sh status
./run_local.sh logs
```

## Docker

```bash
cp env.example .env
docker compose up -d --build
```

预构建镜像和 ARM 说明见 [GHCR 快速部署指南](GHCR快速部署指南.md)。

## 配置

| 变量 | 作用 |
|---|---|
| `DATABASE_URL` | 默认 SQLite。PostgreSQL 用 `postgresql+asyncpg://...` |
| `APP_SECRET_KEY` | 加密访问码和云端令牌。生产环境要换掉默认值 |
| `ALLOW_INSECURE_MQTT_TLS` | 局域网自签证书需要打开。云端 MQTT 仍校验证书 |
| `NEXT_PUBLIC_API_BASE_URL` | 浏览器访问后端的地址 |

## 接入打印机

1. 打印机页扫描局域网，或手填 IP、序列号、访问码。
2. 不必打开「仅局域网」。保持拓竹账号登录，Handy 远程打印可以继续用。
3. 人会离开这个局域网时，到「设置 → 拓竹云账号」登录。序列号相同的机器不会再出现第二条。

库存可以拍照识别，也可以手填。见 [功能说明](功能说明.md)。
